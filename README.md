# Contact Manager

A full-stack Contact Manager application built using React, Node.js, Express, and MongoDB.

## Features

- User registration and login
- Session-based authentication
- Create contacts
- View contacts
- Edit contacts
- Delete contacts
- Search contacts
- Filter contacts by category
- Contact categories
- Contact profile/avatar upload
- Responsive dashboard

## Technologies

### Frontend
- React
- Vite
- React Router
- Tailwind CSS
- Lucide React

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- Multer
- Express Session
